# Responsive Product Landing Page

A clean, modern, and fully responsive **Product Landing Page** built with HTML5, CSS3, and JavaScript.  
Includes a compelling hero, feature highlights, testimonials, pricing plans, newsletter signup, and a contact form with front-end validation—plus smooth interactivity and delightful animations.

## ✨ Key Sections
- **Hero**
  - Product name, tagline/short description
  - Primary CTA (e.g., “Buy Now” / “Sign Up”)
  - Hero image/illustration

- **Features**
  - 3–4 feature cards with icon, title, and description

- **Testimonials / Reviews**
  - 2–3 customer reviews with name, role, text, and optional avatar

- **Pricing / Plans**
  - 2–3 plans with clear CTAs

- **Newsletter Signup**
  - Email input + submit button
  - JavaScript email format validation

- **Contact**
  - Name, Email, Message fields
  - Front-end validation (required fields + email format + min message length)
  - Success confirmation via **modal popup**

- **Footer**
  - Quick links, social icons, copyright

## 🧠 Interactivity & Enhancements
- Smooth scroll navigation
- Hover effects on buttons, cards, and sections
- Animate on scroll (CSS/JS)
- JS form validation for Newsletter + Contact
- Modal confirmation on successful submission
- **Bonus:** Dark/Light mode toggle, animated CTAs & feature cards, **sticky navigation**, scroll-to-top button

## 🛠 Tech Stack
- **HTML5** for semantic structure  
- **CSS3** (Flexbox & Grid) for responsive layout  
- **JavaScript (Vanilla)** for interactivity, validation, and UI state

## 📱 Responsiveness
- Fully responsive across **desktop, tablet, and mobile**
- Consistent color scheme, typography, spacing, and accessible contrast
